# Historias de Usuario

## Proyecto

**ReservaGo**

---

# Introducción

Las historias de usuario describen las necesidades de los diferentes tipos de usuarios que interactuarán con la plataforma.

---

# HU-001 Registro de usuario

Como visitante,

quiero registrarme en la plataforma,

para poder realizar reservas y administrar mi cuenta.

---

# HU-002 Inicio de sesión

Como usuario,

quiero iniciar sesión,

para acceder a mis reservas y perfil.

---

# HU-003 Buscar propiedades

Como huésped,

quiero buscar propiedades por ciudad, municipio, precio y capacidad,

para encontrar el alojamiento que mejor se adapte a mis necesidades.

---

# HU-004 Ver detalles

Como huésped,

quiero visualizar toda la información de una propiedad,

para decidir si deseo reservarla.

---

# HU-005 Reservar propiedad

Como huésped,

quiero solicitar una reserva indicando las fechas de ingreso y salida,

para asegurar mi alojamiento.

---

# HU-006 Contactar propietario

Como huésped,

quiero comunicarme con el propietario mediante WhatsApp,

para resolver dudas antes de viajar.

---

# HU-007 Publicar propiedad

Como propietario,

quiero registrar una propiedad,

para ofrecerla en alquiler.

---

# HU-008 Administrar disponibilidad

Como propietario,

quiero bloquear o habilitar fechas,

para controlar cuándo mi propiedad está disponible.

---

# HU-009 Administrar reservas

Como propietario,

quiero aprobar o rechazar solicitudes,

para controlar quién puede hospedarse.

---

# HU-010 Administrar propiedades

Como propietario,

quiero editar la información de mis propiedades,

para mantenerla siempre actualizada.

---

# HU-011 Consultar ingresos

Como propietario,

quiero visualizar las reservas realizadas y mis ingresos,

para llevar control de mi negocio.

---

# HU-012 Administrar usuarios

Como administrador,

quiero gestionar usuarios y propietarios,

para mantener el correcto funcionamiento de la plataforma.

---

# HU-013 Administrar propiedades

Como administrador,

quiero aprobar, editar o desactivar propiedades,

para garantizar la calidad del contenido publicado.

---

# HU-014 Administrar reservas

Como administrador,

quiero visualizar todas las reservas,

para brindar soporte cuando sea necesario.

---

# HU-015 Gestionar comisiones

Como administrador,

quiero consultar las comisiones generadas,

para controlar los ingresos de ReservaGo.

---

# HU-016 Dashboard

Como administrador,

quiero visualizar estadísticas generales,

para conocer el comportamiento de la plataforma.
