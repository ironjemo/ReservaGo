# ReservaGo

## Plataforma de Reservas Turísticas

ReservaGo es una plataforma web para la gestión de reservas de:

- Apartamentos
- Fincas
- Cabañas
- Glampings
- Casas vacacionales

Inicialmente enfocada en Antioquia, Colombia.
